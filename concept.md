# Аффогато — концепция сайта

Атмосферный скролл-сайт для альбома дарк-фолк группы.
Основная метафора — погружение, встреча с памятью песен и возвращение к началу.

## Сцены по порядку

1. Лоадер — предзагрузка кадров погружения.
2. Погружение под воду — покадровая видео-секвенция.
3. Название группы `АФФОГАТО` и название альбома `после падения` появляются поверх сцены и расходятся по экрану при скролле.
4. Автоматический переход от последнего кадра погружения к следующей части, без ручного скролла в промежуточном участке.
5. Серия песенных сцен — каждая сцена показывает одну потрёпанную полароид-карточку с обложкой песни.
6. Справа от карточки расположен личный текст о песне: когда написана, из какого состояния появилась, о чём были мысли.
7. В подписи полароида указывается отдельный текст, сейчас это год написания песни.
8. После карточек пользователь уходит в темноту.
9. Из темноты запускается автоматический переход к видео с дном и камнем.
10. После окончания видео экран снова уходит в темноту.
11. Быстрый автоматический возврат к самому началу сайта.

## Песенные карточки

Карточки настраиваются в `js/config.js` в блоке `scenes.songs.items`.

Для каждой песни указываются:

- `title` — название песни, выводится справа как заголовок.
- `year` — подпись внутри полароид-карточки.
- `cover` — путь к обложке песни.
- `note` — личный текст о песне.

Обложки песен хранятся в папке `assets/song-covers`.

## Треки

1. Пресловутая гордость
2. После падения
3. Цвела земля

Список можно расширять через `js/config.js`: каждая новая запись в `scenes.songs.items` создаёт отдельную сцену.

## Технический стек

- Чистый HTML/CSS/JS, без фреймворков.
- Покадровая секвенция для сцены погружения.
- DOM-слои поверх canvas для названий и песенных карточек.
- Инерционный скролл написан вручную.
- Защищённые автопереходы для участков, где пользователь не должен вручную управлять скроллом.
- Финальная видео-сцена с автозавершением и возвратом к началу.
