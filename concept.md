# Аффогато — концепция сайта

Атмосферный скролл-сайт для альбома дарк-фолк группы. 
Метафора — погружение и возвращение.

## Сцены по порядку

1. Лоадер — название группы проявляется по мере загрузки
2. Ночной лес с озером (статичная сцена с параллаксом)
3. Пересечение поверхности воды
4. Длинное погружение под воду (видео покадрово)
5. Шесть рун-треков — поочерёдные встречи, при скролле проявляется название трека
6. Дно — пустая тёмная вода без объектов
7. Финальное видео — падение камня с верёвкой и рунами
8. Программный «выброс» наверх
9. Горящий лес — возврат в изменённый мир со ссылками на стриминги

## Треки
1. Имя моё
2. Пресловутая гордость  
3. После падения
4. Вечная жизнь
5. Цвела земля
6. Нам ли с тобой

## Технический стек
- Чистый HTML/JS, без фреймворков
- Параллакс на PNG-слоях
- Покадровые видео-секвенции для движения камеры
- Одно видео для финального падения камня
- Lenis-подобный инерционный скролл (написан вручную)
