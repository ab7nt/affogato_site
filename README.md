# Аффогато

Промо-сайт альбома **«после падения»** группы Аффогато. Скролл-сайт с атмосферным погружением под воду, серией песенных карточек-воспоминаний и финальным возвратом к началу.

Высокоуровневое описание сцен и метафоры — в [`concept.md`](concept.md).

## Запуск

Открыть `index.html` напрямую двойным щелчком — сайт работает по `file://`, локальный сервер не нужен. Целевые браузеры — macOS Safari и Chrome последних версий.

Шрифт Poiret One подтягивается с Google Fonts по https — для него нужен интернет; без сети используется системный sans-serif как fallback.

## Сцены и таймлайн

```
diving → song-0 → song-1 → song-2 → stoneVideo
       ↑──auto──↑──auto──↑──auto──↑──auto──↑
```

Между сценами — короткие автоматические переходы (`scroll.transitionVH`); на их отрезках ручной скролл перехвачен. После завершения `stoneVideo` сайт автоматически возвращается к самому верху через canvas-анимацию `return-ascent`.

## Конфигурация

Всё крутится в [`js/config.js`](js/config.js):

| Блок | Что задаёт |
| --- | --- |
| `scroll` | инерция, длина перехода, длительности автопереходов и возврата к началу |
| `scenes.diving` | длина сцены погружения, динамика старта, тексты и движение титров (с мобильными оверрайдами) |
| `scenes.songs` | длина карточки, прозрачности полароида и текста в воде, амплитуды и скорость дрейфа, массив `items` |
| `scenes.stoneVideo` | путь к финальному видео |
| `underwater` | цвета воды, взвесь, лучи света, прогрессия света по глубине (`depthLight`), «фонарик у дна» (`bottomGlow`) |

Большинство параметров читаются каждый кадр — крутятся вживую в DevTools без перезагрузки.

## Добавить песню

Добавить запись в `Affogato.Config.scenes.songs.items`:

```js
{
  title: 'Название',
  year: 'Год или период',
  cover: 'assets/song-covers/songN.png',
  note: 'Личный текст о песне.',
}
```

Глубина (`depth = index / (count − 1)`) и привязанная к ней прогрессия подводного света (верхний свет гаснет, нижний разгорается) сами перераспределяются на новое число карточек.

## Технические ограничения

- Без фреймворков и сборки — чистый HTML/CSS/JS.
- **Без ES-модулей**: classic `<script>`-теги в `index.html`, общий неймспейс `window.Affogato`. Обязательное условие работы по `file://` в Chrome.
- **Без `fetch()`** для локальных ресурсов: предзагрузка кадров через `new Image()` + `decode()`.
- Целевые браузеры — Safari и Chrome последних версий на macOS.

## Атмосферные эффекты

- **Покадровая секвенция** погружения, синхронизированная со скроллом (~86 кадров).
- **Инерционный скролл** собственной реализации; на стыках сцен — автопереходы.
- **Процедурный подводный фон** на canvas: глубинный градиент, дрейфующая взвесь, мягкие лучи сверху, нижний свет «фонарика». Параметры тянутся к глубине текущей карточки.
- **Дрейф карточки** — мягкое покачивание по синусам разной частоты («висит в воде», а не движение по кругу).
- **Финальный подъём** — отдельная canvas-анимация: стоп-кадр видео уходит вверх, толща воды, обратная прокрутка первой секвенции.
